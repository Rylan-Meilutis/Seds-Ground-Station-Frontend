# 0.4.0 build 40

Version 0.4.0 marks the features added since 0.3.1 (proximity lock,
recovery search, replays without a station, flight plans, crew voice and the
new station modes). The build number keeps counting from 39.

Needs a Ground Station on the current `dev` stack. Boards and station are
updated together; mixing this build with an older station is not supported.

**Requires iOS 15 or later and Android 7 or later.**

## New since build 39

- **Launch refusals explained.** If the station refuses a Launch before
  anything was sent to the rocket, it now says so ("Launch refused, nothing was
  sent; Launch is available again") and Launch can be pressed again. The
  safety reference in the app lists this case.
- **More reliable builds.** The Android, Wear OS and Windows builds no longer
  fail when a download server is busy, so releases reach the stores more
  reliably. No change to how the app works.
