# 0.3.1 build 39

Needs a Ground Station on the current `dev` stack. Boards and station are
updated together; mixing this build with an older station is not supported.

Build 38 reached TestFlight but not Google Play, which now requires Android
API 36. This build targets it.

**Requires iOS 15 or later** (was iOS 14).

## New since build 38

- **Launch mass window.** The GSE settings edit the nitrous mass range in which
  Launch is allowed, on stations that support it.
- **Android API 36.** Required by Google Play.
- **Store requirements.** The iPhone app is built with the iOS 27 SDK, and the
  Android app supports devices with 16 KB memory pages.

## Also new since build 36

- **Replays without a station.** Open a replay file from the connection screen,
  by drag and drop, from recent replays or from another app. Self-contained
  replay bundles carry the layouts, models and recordings, and export to the
  same CSV, Excel and PDF reports the station produces.
- **Flight plans and prediction.** Run flight and burn simulations, play a plan
  as a replay, and see the predicted landing point and area after loss of signal.
- **Maps and recovery.** 3D map and terrain, flight phases by colour, and search
  coverage. Sharing your search track is off until you turn it on.
- **Live diagrams.** One combined view per station mode, with full screen.
- **Streams.** A visual Preview/Program manager replaces the layout drop-downs,
  with live diagrams and telemetry views as sources.
- **Crew voice.** Up to 32 people with a talk floor, built-in noise suppression,
  a Phone or Speaker choice, and the iOS audio fix.
- **Integrated ground test, test fire and simulated firmware** station modes,
  with burn reports and recording reviews.
- **Calibration.** Load cells in volts, refusal of unsteady or clipped captures,
  and a check that stops one editor overwriting another's save.
- **Board health.** Network, state and SD health per board, DAQ input health,
  ADC over-range and power readings.
- **Watch apps.** Configurable pages, push-to-talk voice, cached map and
  predicted rocket position.

## Please test

These compile and pass automated tests, but have not been proven on real devices:

- Voice on iPhone and Android, including Phone/Speaker and Bluetooth headsets.
- The Apple Watch and Wear OS apps.
- Background recording of a shared search track.
